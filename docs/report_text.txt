1. Project Overview
A hybrid hardware-software system that captures physical entropy from dual photodiodes, processes it through a modular C++ backend, validates randomness using Python statistical analysis, and exposes cryptographic applications through a web-based interface.
The primary entropy source is photodiode shot noise conditioned through analog circuitry. Since the generated entropy contains both quantum-origin shot noise and unavoidable classical noise, the project refers to the source as PseudoQuantum Entropy rather than a pure Quantum Random Number Generator (QRNG).
Primary Goal:
Develop a modular hardware-backed entropy service capable of supplying high-quality random data for cryptographic applications while demonstrating complete integration between hardware, C++, Python, and web technologies.
Primary Application (v1.0):
Cryptographic Key Generation 
AES-GCM Image Encryption / Decryption 
Future applications can be added without modifying the entropy generation layer.

6. Communication Protocols
Hardware ↔ C++ Backend
Medium: Serial (USB) 
Baud Rate: 115200 
Protocol: Binary 
Format: [0xAA][Random Byte] 
Validation: Sync marker verification 
Fallback: Automatic switch to OpenSSL entropy source 

C++ Backend ↔ Python Analyzer
Medium: Subprocess (stdin/stdout) 
Protocol: JSON 
Input: Raw entropy bytes 
Output: Statistical analysis results 
Modes: 
Quick Statistical Check 
Full NIST STS Analysis 

C++ Backend ↔ Frontend
Medium: HTTP (REST API) 
Format: JSON 
Port: 8080 (configurable) 
File Upload: multipart/form-data 
Frontend: Served directly by the backend
